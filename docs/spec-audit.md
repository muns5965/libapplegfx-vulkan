## MSAA (three separate facts)
1. Host Vulkan support: not determinable offline. `devinfo.c` prints `framebufferColorSampleCounts` and per-format counts at run time (g7-gpu-vkdev line) [N: no device output in the logs].
2. Implemented by LAGFX at this base: none. Textures with samples > 1 are refused (`arm64_resources.c:661/701`, TEXWHY_C_MSAA), images and pipelines are single-sample (`:403`). The multisample colour path exists only on g7-render-compat (f81c138), behind an internal API.
3. Advertised to the guest: `MSAASamples = 4` (`ops_misc.c:249`), documented as load-bearing for `supportsRasterSampleCount:1` (value >= N gate). Not changed.
Effect on the boot path: [V] `/tmp/x231501/logs` and `/tmp/x230109/dump/index.txt` contain no MSAA/sample-count token; [N] whether the guest ever requested samples > 1 (the exec counters per texture-failure reason are not in those logs). Class G.

## A2Xghfc fragment shader (346,780 B, /tmp/x230109/dump/spv_ce5c70c189b74076_fs.spv) — facts, no causality claimed for -13
[V] spirv-val passes for vulkan1.2 and vulkan1.3 (fails vulkan1.1 only because the module is SPIR-V 1.4); `spirv-opt -O` output (9.5 MB after inlining) also validates. 20,194 disassembly lines; no OpSpecConstant*, no OpKill, no RelaxedPrecision/NoContraction decorations, no OpPhi, no atomics, no barriers.
Constructs tolerated by the spec / validator that a driver compiler might reject (each [V] present, whether any driver rejects it [N]):
1. Capabilities Int64, Float16, Int8, Int16, StorageBuffer16BitAccess, StorageBuffer8BitAccess, VariablePointersStorageBuffer, InputAttachment; only extension string SPV_KHR_8bit_storage. All require device features that `instance.c` enables only when probed; a driver lacking one fails pipeline creation, the library's gate would skip the draw instead (`stub_missing_cap_*`).
2. 16 function parameters of type pointer-to-StorageBuffer, 70 OpPtrAccessChain, 162 OpFunctionCall (needs VariablePointersStorageBuffer; the most exotic feature in the module).
3. 14 OpLoopMerge + 14 OpSwitch from the dispatch lowering (`translate_body_dispatch`: loop + switch over a block index, 65536-iteration bail) inside which OpImageSampleImplicitLod (72), OpDPdx (5) and OpFwidth (16) execute: implicit derivatives in a data-dependent control-flow shape.
4. 13 OpUndef; analysis `spv_undef_flow.py` lists undef 284/886/898 reaching select conditions, OpAccessChain base/index, an image operand and a switch selector (MAY-analysis, over-approximate), whereas the translator's own check reports 0 control sinks for the same module: the two analyses disagree [V]; which is right is [N].
5. 188 OpFConvert (half<->float) without FPRoundingMode; 24 OpUConvert, 3 OpSConvert; one OpConvertFToU and one FToS.
6. Two Output vec4 at Location 0/1, FragCoord + PointCoord inputs, input-attachment OpImageRead x2; Int64 type declared (1 OpTypeInt 64) and Int8/Int16 types.
7. 4 OpBitwiseOr of (sign mask | 0x3FC90FDB) — same shape as aerogauge-recomp PR #61 (compute, Adreno 750); applicability [N], untested.
8. 9 OpTypeArray, 4 OpTypeRuntimeArray; 25 StorageBuffer pointer types; 28 function types.

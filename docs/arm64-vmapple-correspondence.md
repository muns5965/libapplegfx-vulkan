# ARM64 vmapple (Apple Henge) vs LAGFX correspondence

Baselines: Apple Henge `research/android-port` 53f0d72 (devices/pvg_lite.c, pvg_metal.m); LAGFX `research/android-pfn-shift`
c53dcb5 (the APK build), 32ea2c3 (0x25/0x20 change, not in any APK), this commit. Select with `lagfx_device_descriptor_t.protocol_mode`.

## MMIO (gfx BAR)
| offset | Apple Henge gfx_read/gfx_write | LAGFX doorbell.c | status |
|---|---|---|---|
| 0x100c | read: do_root(), returns cumulative root_rp | shadow register, root ring not run on read | 오류 (미수정) |
| 0x1014 | plain register | atomic xchg display bitmask | 다름 (미확인 영향) |
| 0x1018 | atomic xchg status | atomic xchg stamp bitmask | 대체 |
| 0x1008/0x1020 | write: do_root / do_channel | dispatcher | 대체 |
| 0x1220 | write: cursor_moved (metal) | none | 미구현 |
| 0x122c | 1 | 9 (x86) / 1 (arm64 mode, this commit) | 수정(arm64 모드) |
| 0x1000-0x1fff | regs[] 전체 저장 | 0x1000-0x103f only (idx<16) | 부분 (미수정) |
| root rp | cumulative u32, `% ring` only at access | `(rp+len) % ring_size` | 다름 (미수정) |

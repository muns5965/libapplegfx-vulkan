# AIR atomics: what the translator supports (classification)

Scope: `air.atomic.<global|local>.<op>[.<s|u>].<i32|i64|f32>` and the compare-exchange family, as translated by
`src/air2spv/translate_function.c` (`parse_atomic_name`, `emit_atomic_call`). Default (strict) mode. Verification level of every row: **host-translated only**
(SPIR-V produced and `spirv-val`-checked / run on lavapipe by the existing atomic tests). **Nothing here is device-verified or guest-verified.**

Classes (generated by `tests/air2spv-atomic-matrix-unit.c`, one module per cell, expectation written as an independent oracle in the test):

- **SUPPORTED_V** - translates and the spelling was seen in a real Apple module: `global.{load,store,xchg}.i32`, `global.{add,and,or}.u.i32` (6 spellings).
- **SUPPORTED_N** - translates by grammar extrapolation; the spelling was never observed (104 cells, includes every `local.*`, sub/xor/min/max, cmpxchg, and all 64-bit forms).
- **REFUSED(reason)** - refused with a named `LAGFX_ATOMIC_R_*` reason (88 cells: 76 spelling, 6 float, 6 i64_return).

Total 198 cells = 6 V + 104 N + 88 refused. Full per-cell table: `docs/evidence/air-atomic-matrix.tsv`.

## Supported (partial where noted)

| area | status |
|---|---|
| i32 load/store/xchg/add/sub/and/or/xor/min/max, global (StorageBuffer, Device scope) and local (Workgroup) | supported; only 6 spellings are V, the rest N |
| memory order | **only literal 0 (relaxed)**; any other order refused (`order`), also in lenient mode |
| scope operand | strict: literal 2 only; SPIR-V scope follows the checked storage class, not the operand |
| i64 store / rmw (void-declared) | **partial**: accepted for every op and for local memory too, which is wider than MSL (MSL has `atomic_ulong` min/max in device memory only). Harmless superset today, spelling unverified |
| i64 load or non-void i64 rmw | refused (`i64_return`): real AIR return type unknown |
| f32 add | refused in strict (`float`); accepted under `LAGFX_ATOMIC_LENIENT=1` with `AtomicFloat32AddEXT` (needs the device feature) |
| f32 load/store/xchg/sub/min/max | unimplemented (`spelling`), never emulated |
| add/sub/min/max without `.s`/`.u` | refused (`spelling`): signedness is part of the spelling |
| cmpxchg (weak / strong / no word) | **partial**: one synthetic form only (expected by pointer in function memory, i1 result); other forms refused (`cas_form`); the real Apple operand layout is unknown |
| cmpxchg f32 | unimplemented |
| `air.atomic.fence` and any other name | unimplemented (`spelling`) |
| atomic in a helper whose call cannot be wired | refused (`helper`) |

## Not covered by this matrix (separate tests)

Operand-shape refusals (scope/extra/flag/arg count) are in `air2spv-atomic-strict-unit`; SPIR-V validity in `air2spv-atomic-spv-unit`; execution on lavapipe in `air2spv-atomic-lavapipe`.
Still open: the real AIR spelling and operand layout for cmpxchg, non-relaxed orders, scopes other than 2, 64-bit return types and float atomics need modules compiled by Apple's toolchain; none of that can be verified here.
